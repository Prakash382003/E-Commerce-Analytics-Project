
# E-Commerce-Analytics-Project

## 📊 Project Overview

This project is an end-to-end E-Commerce Data Analytics project focused on analyzing customer and business data to generate meaningful insights and support data-driven decision making.

The project covers data analysis using **SQL, Microsoft Excel, and Power BI**, following a structured analytics workflow from raw data to business insights and dashboard visualization.

## 🎯 Project Objectives

- Analyze customer and e-commerce data
- Perform data cleaning and validation
- Explore customer demographics and purchasing patterns
- Perform SQL-based data analysis
- Analyze data using Microsoft Excel
- Create interactive Power BI dashboards
- Generate meaningful business insights
- Present the complete analytics workflow professionally

## 🗂️ Dataset

The project uses an e-commerce dataset containing **5,000 customer records** along with supporting business data.

Main datasets include:

- Customers
- Orders
- Products
- Categories
- Payments
- Shipping
- Reviews
- Returns

## 🛠️ Tools & Technologies

- **SQL Server / SSMS** – Data querying and analysis
- **Microsoft Excel** – Data analysis, validation, Pivot Tables and visualization
- **Power BI** – Interactive dashboard and business intelligence
- **GitHub** – Project documentation and version management

## 🔎 SQL Analysis

SQL was used to perform different analytical tasks including:

- Data exploration
- Customer analysis
- GROUP BY and aggregate analysis
- JOIN operations
- Duplicate and data-quality checks
- Customer segmentation
- State and city-wise analysis
- Gender-wise analysis
- Revenue and order analysis
- MIN, MAX and AVG calculations

The SQL work was completed through structured day-wise analytical tasks.

## 📈 Excel Analysis

Microsoft Excel was used for:

- Data validation
- Duplicate checking
- Blank-cell checking
- Customer analysis
- Average age calculation
- Gender analysis
- State-wise analysis
- Customer segmentation
- Pivot Tables
- Charts and KPI-based analysis

### Key Excel Results

- Total Customers: **5,000**
- Average Customer Age: **39.10**
- Male Customers: **2,908**
- Female Customers: **2,092**
- Regular Customers: **2,477**
- Gold Customers: **944**

## 📊 Power BI Dashboard

Power BI was used to transform the analyzed data into an interactive business dashboard.

The dashboard focuses on:

- Customer overview
- Demographic analysis
- Customer segmentation
- State and city analysis
- Business KPIs
- Interactive visualizations

## 💡 Key Business Insights

The analysis helped identify patterns in:

- Customer demographics
- Gender distribution
- State and city-wise customer concentration
- Customer segmentation
- Purchasing and revenue behavior
- Order and payment-related trends

These insights can help businesses understand their customers and make better data-driven decisions.
